# macOS Systems Administration

Collection of macOS systems administration scripts, focused on Jamf Pro fleet management.

## Scripts

- **Jamf API Interaction Template** — Base template for Jamf Pro API calls
- **Convert CSV to Static Group** — Import CSV data into Jamf static computer groups
- **Clear Touch ID on Password Change** — Reset Touch ID enrollment when a user's password changes
- **Enforce CIS Standards for macOS 10.14 Sonoma** — Apply CIS benchmark settings
- **jamf_telemetry_tool** — Fleet telemetry collection

## Usage

Each script is standalone. Review the header comments in each file for parameters and requirements before running against a production Jamf instance.
